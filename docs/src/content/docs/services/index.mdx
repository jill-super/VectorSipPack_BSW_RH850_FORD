# Services

The AUTOSAR **Services** layer groups system-wide infrastructure: OS, ECU/mode
management, diagnostics, NVRAM, crypto dispatch, communication management, and
supervision. In this repo the Services-layer modules are documented under the
topic sections below (grouped so each module lives in exactly one place).

## System & lifecycle

| Module | Responsibility | Origin |
|--------|----------------|--------|
| [Os](../modules/system/Os/) | AUTOSAR OS: tasks, alarms, applications, protection | ![o](https://img.shields.io/badge/origin-Vector--provided-blue) |
| [BswM](../modules/system/BswM/) | Mode arbitration and action lists | ![o](https://img.shields.io/badge/origin-Vector--provided-blue) |
| [EcuM](../modules/system/EcuM/) | ECU startup/shutdown/sleep/wake | ![o](https://img.shields.io/badge/origin-Vector--provided-blue) |
| [WdgM](../modules/system/WdgM/) | Software supervision (checkpoints, deadlines) | ![o](https://img.shields.io/badge/origin-Vector--provided-blue) |
| [Crc](../modules/system/Crc/) | CRC library | ![o](https://img.shields.io/badge/origin-Vector--provided-blue) |
