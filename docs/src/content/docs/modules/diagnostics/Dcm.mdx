## Purpose

Implements UDS diagnostic services (sessions, security access, DID/routine handling, upload/download) on top of CanTp/PduR and Dem.

> Header brief (`BSW/Dcm/Dcm.h`): *Public interface of DCM for other components*

**AUTOSAR group:** Services / Diagnostic Communication Manager · **Docs layer:** [Diagnostics](../../diagnostics/)
