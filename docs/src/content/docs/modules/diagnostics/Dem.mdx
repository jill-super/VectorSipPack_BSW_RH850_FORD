## Purpose

Stores and manages diagnostic events, DTCs, freeze frames, debouncing and enabling conditions; front-end for Dcm fault-memory access.

**AUTOSAR group:** Services / Diagnostic Event Manager · **Docs layer:** [Diagnostics](../../diagnostics/)
