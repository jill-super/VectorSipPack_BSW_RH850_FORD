## Purpose

Central development-error hook: modules report errors via Det_ReportError; supports filtering and forwarding during development.

> Header brief (`BSW/Det/Det.h`): *Header of Default Error Tracer*

**AUTOSAR group:** Services / Development Error Tracer · **Docs layer:** [Diagnostics](../../diagnostics/)
