## Purpose

AUTOSAR OS services used by this SIP: tasks, alarms, counters, applications/partitions, protection (memory/timing), multi-core primitives. Sources here are the OS abstraction headers plus kernel objects; configuration is generated by DaVinci Configurator.

> Header brief (`BSW/Os/Os.h`): *User API of MICROSAR OS*

**AUTOSAR group:** Services / Operating System · **Docs layer:** [System & libraries](../../system/)
