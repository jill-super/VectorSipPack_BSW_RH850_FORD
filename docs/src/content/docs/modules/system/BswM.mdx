## Purpose

Arbitrates vehicle/ECU modes and executes mode-dependent action lists (maps BswM action lists to ComM, EcuM, Nm, PduR, WdgM, DCM requests).

> Header brief (`BSW/BswM/BswM.h`): *Header file of MICROSAR Basic Software Mode Manager*
