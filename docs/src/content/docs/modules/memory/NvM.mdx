## Purpose

Manages non-volatile data blocks: read/write/restore, job queuing, CRC protection and coordination with MemIf/Fee at shutdown and startup.

**AUTOSAR group:** Services / NVRAM Manager · **Docs layer:** [Memory stack](../../memory/)
