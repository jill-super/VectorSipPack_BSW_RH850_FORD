# ThirdParty MCAL integration

![origin](https://img.shields.io/badge/origin-third--party%20via%20Vector-orange)

:::note[Origin: Third-party (Renesas) via Vector]
`ThirdParty/Mcal_Rh850P1xC/` holds the Renesas RH850/P1x-C MCAL integration: `VectorIntegration/` (`MIPconfig.xml`, `Script_MCAL_Prepare.bat`, `Patches/`) adapts the Renesas delivery to the MICROSAR build. Renesas license terms apply to MCAL sources.
:::

Delivery docs: `Doc/TechnicalReferences/TechnicalReference_3rdParty-MCAL-Integration.pdf` and `Doc/ReleaseNotes/ReleaseNotes_3rdPartyMCAL_VectorIntegration.pdf` (see converted summaries under [Delivery documents](../../general/delivery-docs/)).
