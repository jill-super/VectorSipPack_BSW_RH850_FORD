## Purpose

Dispatches cryptographic jobs (encrypt/decrypt, MAC generate/verify, RNG, key handling) to crypto drivers (Cry_30_LibCv, Cry_30_Rh850Icum, CryFord).

> Header brief (`BSW/Csm/Csm.h`): *MICROSAR Crypto Service Manager (CSM)*

**AUTOSAR group:** Services / Crypto Service Manager · **Docs layer:** [Crypto](../../crypto/)
