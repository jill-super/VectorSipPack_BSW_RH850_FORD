## Purpose

Bus state machine per CAN network (init, start/stop, bus-off recovery, Tx timeout handling) coordinated with ComM and BswM.

> Header brief (`BSW/CanSM/CanSM.h`): *Public header of the CAN State Manager AUTOSAR Release 4*
