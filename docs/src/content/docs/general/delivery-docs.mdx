# Delivery documents

Every PDF under `Doc/` (plus the root `DocumentationGuide_VectorAUTOSAR.pdf` and the
DaVinci automation-interface doc) has a converted summary page below. Summaries state
their limits explicitly; the PDFs remain authoritative.

:::note[Why summaries, not full conversions?]
Vector Technical References are long, layout-heavy PDFs (figures, tables, change
histories). Automated text extraction preserves searchability but not layout, so each
page keeps document facts + an extracted excerpt and links the original.
:::
